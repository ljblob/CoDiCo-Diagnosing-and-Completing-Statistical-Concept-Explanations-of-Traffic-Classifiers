# CoDiCo: Diagnosing and Completing Statistical Concept Explanations of Traffic Classifiers

This repository provides the supplementary material for **CoDiCo**, a framework for diagnosing information omissions in statistical concept explanations of traffic classifiers and recovering missing classifier responses using compact, interpretable statistical concepts.

CoDiCo consists of three stages: **Diagnose, Induce, and Recover**.

## Supplementary Material

The supplementary material includes implementation details and theoretical analysis of response-error reduction.
